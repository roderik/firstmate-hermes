# Home brief additions

Use the repository's own instructions and skills as the source of truth for implementation and delivery.

## Delivery chain

For a build, use the repository's planning and work skills, then run local checks, simplify the change, review the committed diff, and publish through the configured delivery path.

For a backend-only change, record that no browser surface is affected.

Open pull requests ready for review and include the validation evidence required by the repository.

## Safety

Do not commit private preferences, credentials, hostnames, account names, or project-specific data.
